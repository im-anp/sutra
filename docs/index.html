sutra

Your second brain,
on your own Mac.

Sutra remembers what you tell it, reads your documents and email, searches and reads the web, works in your tools, helps you learn things properly — and hands builds to Claude Code or Codex. Its memory is a folder of plain markdown you own.

install
curl -fsSL https://raw.githubusercontent.com/im-anp/sutra/main/install.sh | bash

Needs macOS on Apple Silicon, Node 24+, and an OpenRouter key. Then run sutra.

What it does

Memory you own

Plain markdown in a folder — open it in Obsidian. Local search, on-device embeddings.

Web, fast

Search the web, read any page or PDF as clean markdown, crawl a docs site.

Your tools

Gmail, Calendar, Jira, Notion, Slack, GitHub — connect with a click.

Learning

Study plans from real sources, review cards, spaced repetition.

Coding agents

“Have Claude Code build X” — it runs in the background, you watch it live.

Asks first

Anything that sends, posts, buys or changes something waits for your yes.

Using it

  1. sutra — start it; it opens in your browser at localhost:3000
  2. sutra update — move to the latest version
  3. sutra key — replace your OpenRouter key
  4. sutra doctor — check the install

Privacy

Sutra runs entirely on your machine and only answers your machine — there is no account and no sign-in; whoever uses this computer is treated as you. Your notes, email and logins stay local. Model calls go to OpenRouter with your own key.
